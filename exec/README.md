## 제출 기준

- 소스코드와 빌드 파일은 팀별 GitLab 프로젝트에 정리합니다.
- 포팅 문서는 `exec/1` 아래 문서를 기준으로 확인합니다.
- 외부 서비스 키, 토큰, 계정 비밀번호는 저장소에 포함하지 않습니다.
- DB 데이터는 사용 중 생성되고 그때그때 소비되는 실행 기록, 대화, 연결 상태가 중심이므로 별도로 보존해 복원해야 할 기준 데이터는 없습니다.
