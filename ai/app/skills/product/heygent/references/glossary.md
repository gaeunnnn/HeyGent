# Glossary

- TaskRun: 사용자 요청 하나를 처리하는 실행 묶음입니다.
- StepRun: TaskRun 안의 실행 단계입니다.
- Agent loop: AI가 생각, 도구 호출, 결과 관찰, 다음 행동 결정을 반복하는 구조입니다.
- Tool runtime: AI가 터미널, 파일, 웹, 외부 서비스 같은 도구를 실제로 실행하는 계층입니다.
- Skill: 특정 작업을 잘 수행하기 위한 절차, 참고 문서, 런타임 도구 규칙 묶음입니다.
- Team lead agent: 사용자 요청을 받고 세션 에이전트에게 작업을 배정하는 메인 에이전트입니다.
- Session agent: 세션 안에서 특정 역할을 맡는 에이전트입니다.
- Local bridge: 사용자 PC와 클라우드 AI를 연결해 제한된 범위 안에서 로컬 작업을 위임하는 프로그램입니다.
- Memory: 사용자 선호와 반복 절차를 저장하고 필요한 순간 다시 불러오는 장기기억 계층입니다.
