# Capability Map

## 요청 이해와 작업화

- 자연어 요청을 받아 TaskRun으로 만들고 실행 상태를 관리합니다.
- 긴 요청은 StepRun으로 나누어 모델 호출, 도구 실행, 승인 대기, 결과 정리를 기록합니다.
- 사용자는 작업이 멈췄는지, 진행 중인지, 완료됐는지 확인할 수 있습니다.

## 에이전트와 스킬

- 팀장 에이전트가 사용자 요청을 받고 필요한 역할과 스킬을 판단합니다.
- 세션 에이전트는 역할, 지침, 스킬 구성을 바탕으로 작업을 맡습니다.
- 스킬은 제품 지식, 실행 절차, 도구 사용 규칙, 참고 문서를 함께 제공합니다.

## 작업 보드

- 작업, 담당자, 상태, 댓글, 하위 작업 관계, 실행 이력을 보관합니다.
- 단순 채팅 로그보다 업무 흐름을 다시 찾기 쉽습니다.
- 진행 중인 작업을 화면에서 확인하고 후속 요청으로 이어갈 수 있습니다.

## 실시간 상태

- TaskRun과 StepRun 이벤트를 WebSocket으로 화면에 반영합니다.
- 이벤트 시퀀스를 바탕으로 화면 복구와 진행 추적을 안정적으로 가져갑니다.
- 사용자는 긴 작업도 중간 상태를 확인할 수 있습니다.

## 외부 연동과 실행

- Notion, Gmail, Mattermost, SRT, 한국 생활 정보, 건강 데이터 같은 스킬을 연결할 수 있습니다.
- 로컬 브릿지는 제한된 워크스페이스 안에서 사용자의 PC 작업을 위임받을 수 있습니다.
- IoT 디스플레이와 모바일 알림은 작업 상태를 다른 화면으로 확장합니다.
