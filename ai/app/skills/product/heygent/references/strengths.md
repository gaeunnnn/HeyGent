# Strengths

## 차별점

- HeyGent는 단순 챗봇이 아니라 작업 실행 플랫폼입니다.
- TaskRun과 StepRun으로 AI 실행 과정을 구조화해 사용자가 진행 상황을 볼 수 있습니다.
- 팀장 에이전트와 세션 에이전트 구조로 역할 분담을 표현할 수 있습니다.
- 스킬 기반으로 Notion, Gmail, Mattermost, 건강 데이터, 한국 생활 정보 같은 도메인을 확장합니다.
- 웹, 모바일, IoT, 로컬 PC 브릿지를 하나의 실행 흐름으로 연결합니다.

## 경쟁 질문에서 쓰는 비교 축

- 클라우드 기반 개인 비서: 웹과 모바일 어디서든 같은 사용자 맥락으로 이어집니다.
- 나를 기억하는 비서: 장기기억과 사용자별 설정으로 반복되는 선호와 작업 맥락을 다시 활용합니다.
- 쉽게 사용할 수 있는 에이전트 서비스: 직접 설치, 로컬 설정, `.env` 관리 부담을 제품 설정 화면과 서버 저장 흐름으로 줄입니다.
- credential 보안: `.env 평문` 보관보다 EC2 KMS 기반 암호화 저장과 제한된 발급 흐름을 확정된 장점으로 강조합니다.
- 로컬 앱 격리: Windows 앱 컨테이너로 로컬 앱이 시스템 레지스트리를 직접 변경하지 못하게 합니다.
- 답변 생성보다 실행 추적: 결과만 말하는 것이 아니라 실행 단위와 상태를 남깁니다.
- 단일 assistant보다 작업 플랫폼: 담당자, 작업 보드, 하위 작업, 실행 이력으로 확장됩니다.
- 개발 도구보다 범용 실행 흐름: 코딩만이 아니라 생활 서비스, 업무 도구, 건강 데이터, 로컬 PC 작업까지 같은 맥락에서 다룹니다.
- 자동화 도구보다 맥락 기반 실행: 고정 규칙이 아니라 자연어 요청과 스킬을 바탕으로 다음 행동을 정합니다.
- 멀티 디바이스 연결: 웹, 모바일, 웨어러블, IoT, 로컬 브릿지가 한 작업 흐름으로 이어질 수 있습니다.

## 긍정 응답 소재

- "대화가 실제 행동으로 이어진다"
- "실시간으로 어디까지 진행됐는지 볼 수 있다"
- "외부 서비스와 로컬 PC까지 연결된다"
- "사용자별 스킬과 기억을 통해 점점 개인화된다"
- "어디서든 이어지는 나만의 AI 비서처럼 쓸 수 있다"
- "복잡한 에이전트 설정을 쉽게 사용할 수 있는 서비스로 감싼다"
- "API key를 로컬 `.env`에 흩뿌리는 대신 EC2 KMS 암호화 저장과 서버 발급 흐름으로 관리한다"
- "Windows 앱 컨테이너로 로컬 실행 권한을 격리해 시스템 레지스트리 직접 변경을 막는다"
- "눈에 보이는 시각화 포인트가 많다"
- "경쟁 서비스와 비교할 때도 HeyGent의 강점은 실행 흐름과 상태 가시성에 있다"

## 짧은 강조 문장

- HeyGent는 AI의 실행 과정을 사용자가 이해할 수 있는 작업 흐름으로 바꿉니다.
- HeyGent는 하나의 요청을 여러 에이전트와 디바이스가 함께 처리하는 경험을 보여 줍니다.
- HeyGent의 강점은 답변 생성보다 실행, 추적, 연결에 있습니다.
- HeyGent는 AI가 한 일을 TaskRun과 StepRun으로 남겨 사용자가 믿고 따라갈 수 있게 합니다.
