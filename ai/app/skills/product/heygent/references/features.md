# Feature Map

## AI 채팅 및 작업 실행

- 사용자의 자연어 요청을 TaskRun으로 만들고 실행합니다.
- 긴 요청은 여러 StepRun으로 나눠 모델 호출, 도구 실행, 승인 대기, 결과 정리를 기록합니다.
- 채팅은 단순 답변뿐 아니라 파일, 외부 서비스, 작업 보드, 브릿지 실행으로 이어질 수 있습니다.

## 에이전트 오케스트레이션

- 팀장 에이전트가 사용자 요청을 먼저 받고, 세션 에이전트의 역할과 스킬을 보고 담당자를 배정합니다.
- 개발, UX, K-서비스, 헬스, Gmail, HeyGent 같은 역할별 에이전트를 세션에 둘 수 있습니다.
- 작업 보드에서 담당자, 상태, 댓글, 실행 이력, 하위 작업 관계를 관리합니다.

## 스킬 기반 실행

- Notion, Gmail, Mattermost, SRT, 한국 생활 정보, 건강 데이터, 디자인/프로토타입 같은 스킬을 사용할 수 있습니다.
- 스킬은 단순 프롬프트가 아니라 실행 절차, 참고 문서, 런타임 도구 사용 규칙을 묶은 지식 단위입니다.
- 사용자는 설정에서 스킬을 켜고 끌 수 있고, 에이전트별로 필요한 스킬을 연결할 수 있습니다.

## 실시간 시각화

- TaskRun과 StepRun 진행 상태를 웹 화면에서 실시간으로 보여 줍니다.
- 에이전트 시각화 화면은 누가 어떤 작업을 담당하는지 직관적으로 보여 주는 프로젝트 포인트입니다.
- 작업 흐름은 이벤트, 단계 카드, flow API로 복원됩니다.

## 멀티 디바이스

- 웹은 채팅, 작업 보드, 에이전트 시각화, 설정을 담당합니다.
- 모바일은 채팅, 건강 데이터, FCM 알림, STT 흐름을 담당합니다.
- Galaxy Watch와 Samsung Health 데이터는 헬스 에이전트가 컨디션 참고 코칭에 활용합니다.
- IoT 디스플레이는 MQTT로 작업 상태를 표시합니다.
- 로컬 브릿지는 사용자의 PC 작업을 제한된 워크스페이스 안에서 위임받아 실행합니다.
