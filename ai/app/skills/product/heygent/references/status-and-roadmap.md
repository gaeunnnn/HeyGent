# Status And Roadmap

## 현재 강하게 말할 수 있는 것

- HeyGent는 사용자 요청을 TaskRun과 StepRun으로 구조화합니다.
- 팀장 에이전트와 세션 에이전트, 스킬을 통해 역할 기반 실행 흐름을 만들 수 있습니다.
- 작업 보드와 실시간 상태를 통해 긴 작업의 진행을 보여 줄 수 있습니다.
- 클라우드 기반 서비스로 웹과 모바일 어디서든 같은 작업 맥락을 이어가는 방향입니다.
- 장기기억과 사용자별 설정으로 반복되는 맥락을 기억하는 개인 비서 경험을 만들 수 있습니다.
- provider credential은 backend에서 암호화 저장하고 AI 서버가 필요한 시점에 발급받는 흐름이 있습니다.
- 배포 환경에서는 credential을 암호화 저장해 `.env 평문` 보관 부담을 줄이는 보안 설계를 확정했습니다.
- Windows 로컬 앱은 앱 컨테이너로 띄워 시스템 레지스트리를 직접 변경하지 못하게 하는 보안 설계를 확정했습니다.
- 웹, 모바일, Galaxy Watch, IoT 디스플레이, 로컬 브릿지를 하나의 제품 맥락으로 묶는 방향입니다.
- 상태와 실행 근거를 보여 주는 방향이 HeyGent의 핵심입니다.

## 조심해서 말할 것

- 모든 외부 서비스를 완전 자동으로 조작한다고 말하지 않습니다.
- 모든 로컬 PC 작업을 자유롭게 수행한다고 말하지 않습니다.
- 의료 진단, 법률 판단, 금융 판단을 대체한다고 말하지 않습니다.
- 경쟁 서비스보다 모델 성능이 높다고 말하지 않습니다.
- credential 암호화 저장과 Windows 앱 컨테이너가 모든 보안 위험을 완전히 없앤다고 말하지 않습니다.

## 확장 방향

- 더 많은 스킬을 추가해 업무와 생활 서비스 범위를 넓힐 수 있습니다.
- 작업 보드와 실행 기록을 강화해 팀 단위 협업으로 확장할 수 있습니다.
- 로컬 브릿지의 안전 범위를 정교화해 PC 작업 연결성을 높일 수 있습니다.
- 메모리와 개인화 흐름을 강화해 반복 작업의 품질을 높일 수 있습니다.
- credential 암호화 저장과 Windows 앱 컨테이너 격리를 기준으로 보안 설명을 더 선명하게 만들 수 있습니다.

## 답변 예시

```text
좋습니다. 현재 HeyGent의 핵심은 완전 자동화보다 사용자가 믿고 맡길 수 있는 실행 흐름입니다.
TaskRun과 StepRun으로 상태와 실행 근거를 남기고, 작업 보드와 실시간 이벤트로 진행을 보여 줍니다.
그렇지만 이 구조는 스킬, 외부 연동, 로컬 브릿지, 멀티 디바이스 경험을 계속 확장하기 좋은 기반입니다.
```
