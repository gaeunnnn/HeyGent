# HeyGent Overview

HeyGent는 웹, 모바일, Galaxy Watch, IoT 디스플레이, 로컬 PC 브릿지를 하나로 잇는 멀티 디바이스 AI 오케스트레이션 서비스입니다.

핵심 가치는 "채팅으로 답만 받는 AI"가 아니라 "사용자 요청을 실제 작업 실행 흐름으로 바꾸는 AI 작업 플랫폼"입니다. 사용자가 자연어로 요청하면 HeyGent는 의도를 파악하고, 필요한 작업을 나누고, 에이전트와 스킬, 도구, 외부 서비스를 연결해 실행합니다.

서비스의 첫인상은 다음 문장으로 설명하면 좋습니다.

- HeyGent는 사용자의 요청을 여러 실행 단계로 나누고, 각 단계를 웹과 모바일에서 실시간으로 보여 주는 AI 오케스트레이션 플랫폼입니다.
- Notion, Gmail, Mattermost, SRT, 한국 생활 정보, 건강 데이터 같은 스킬을 연결해 대화가 실제 행동으로 이어지게 합니다.
- 작업 진행 상황은 TaskRun과 StepRun으로 기록되고, WebSocket으로 화면에 실시간 반영됩니다.
- 로컬 브릿지를 통해 사용자의 PC 작업까지 안전하게 이어질 수 있습니다.

한 줄 설명:

> HeyGent는 사용자의 한 문장 요청을 여러 AI 작업과 멀티 디바이스 실행 흐름으로 바꾸는 서비스입니다.
