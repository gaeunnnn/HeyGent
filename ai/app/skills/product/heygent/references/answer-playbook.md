# Answer Playbook

## 기본 톤

- 첫 문장은 긍정적으로 시작합니다.
- 답변은 제품 설명처럼 말합니다.
- 질문이 공격적이어도 상대를 반박하는 데 오래 쓰지 말고, HeyGent가 해결하는 문제로 빠르게 돌립니다.
- 모르는 경쟁사 세부 기능은 단정하지 않고, 공개적으로 확인 가능한 범위와 HeyGent 내부 구조를 분리해서 말합니다.

## 3문장 기본형

```text
좋습니다. HeyGent는 단순히 답을 주는 AI가 아니라, 사용자의 요청을 실제 작업 흐름으로 바꾸는 플랫폼입니다.
요청은 TaskRun과 StepRun으로 나뉘고, 에이전트와 스킬, 도구, 외부 연동이 하나의 실행 기록으로 이어집니다.
그래서 사용자는 결과만 기다리는 것이 아니라 누가 무엇을 처리 중인지, 어디까지 진행됐는지, 다음에 무엇을 할 수 있는지를 확인할 수 있습니다.
```

## 부정 질문 대응형

```text
좋은 질문입니다. 그 부분은 짧게 보면 [제약 또는 리스크]가 있습니다.
그렇지만 HeyGent는 현재 [검증 가능한 기능]을 통해 [사용자 가치]를 만들 수 있고, 이 구조 덕분에 [확장 방향]으로 자연스럽게 넓힐 수 있습니다.
```

## 경쟁 비교 대응형

```text
좋습니다. [경쟁 서비스]도 [상대 강점]이 분명한 서비스입니다.
그렇지만 HeyGent는 [비교 축]에서 강점이 있습니다. 사용자의 요청을 TaskRun과 StepRun으로 구조화하고, 작업 보드, 실시간 상태, 스킬, 멀티 디바이스 연동까지 하나의 실행 흐름으로 묶는 점이 핵심입니다.
```

OpenClaw 질문은 클라우드/쉬운 사용/보안을 먼저 답합니다.

```text
좋습니다. OpenClaw는 직접 설치하고 운영하는 self-hosted assistant 성격이 강합니다.
그렇지만 HeyGent는 웹과 모바일 어디서든 이어지는 나를 기억하는 클라우드 비서이고, 사용자가 복잡한 로컬 설정 없이 로그인해서 바로 맡길 수 있게 만든 서비스형 경험이 강점입니다.
보안 면에서도 `.env 평문` 보관보다 credential 암호화 저장을 사용하고, Windows 로컬 앱은 앱 컨테이너로 격리해 시스템 레지스트리 직접 변경을 막는 구조를 가져갑니다.
TaskRun과 StepRun은 그 뒤에 실행 상태와 근거를 보여 주는 보조 장점으로 덧붙입니다.
```

## 자주 나오는 공격 질문

- "그냥 ChatGPT 쓰면 되는 거 아닌가요?"
  - ChatGPT는 대화와 추론이 강합니다. HeyGent는 그 다음 단계인 실행 단위, 담당자, 상태, 기록, 외부 연동을 제품 흐름으로 묶는 쪽에 초점을 둡니다.
- "OpenClaw보다 뭐가 낫나요?"
  - OpenClaw는 개인 기기와 채널 중심의 로컬 AI assistant 성격이 강합니다. HeyGent는 작업 상태, 담당자, 실행 근거, 웹/모바일/웨어러블/IoT/로컬 브릿지를 한 흐름으로 보여 주는 작업 실행 플랫폼으로 답합니다.
- "완전 자동화가 안 되면 약한 것 아닌가요?"
  - 완전 자동화보다 중요한 것은 안전하게 맡기고 확인할 수 있는 흐름입니다. HeyGent는 승인, 기록, 상태 복구, 제한된 실행 범위를 통해 신뢰 가능한 자동화로 넓혀 갈 수 있습니다.
- "기존 업무관리 도구와 뭐가 다른가요?"
  - 업무관리 도구는 사람이 작업을 정리합니다. HeyGent는 자연어 요청에서 실행 단위를 만들고, 에이전트와 스킬이 실제 처리 흐름까지 이어지도록 설계되어 있습니다.

## 답변 마무리

- 마지막 문장은 "그래서 HeyGent의 강점은 [핵심 가치]입니다." 형태로 닫습니다.
- 장황하게 방어하지 않습니다.
- 미완성 영역은 짧게 말하고 "그렇지만" 뒤에 현재 가능한 흐름을 붙입니다.
