# Product Flow

## 기본 프로젝트 흐름

1. 웹 또는 모바일에서 사용자가 자연어 요청을 입력합니다.
2. HeyGent가 요청을 TaskRun으로 만들고 실행을 시작합니다.
3. 실행 과정은 StepRun으로 나뉘어 모델 호출, 도구 실행, 담당자 배정, 결과 정리로 이어집니다.
4. 필요한 경우 Notion, Gmail, Mattermost, K-서비스, 헬스 같은 스킬이 선택됩니다.
5. 작업 보드에서 담당자, 상태, 댓글, 실행 이력이 연결됩니다.
6. 모바일, IoT, 브릿지 같은 디바이스 계층으로 작업 상태와 결과가 이어질 수 있습니다.

## 빠른 설명 포인트

- "채팅 입력이 실제 작업 단위로 바뀐다"가 첫 번째 포인트입니다.
- "진행 상황이 실시간으로 보인다"가 두 번째 포인트입니다.
- "여러 디바이스와 외부 서비스로 이어진다"가 세 번째 포인트입니다.

## 질문 대응 축

예상 질문을 맞히려고 하기보다 아래 축으로 답합니다.

- 사용자 가치: 왜 필요한가
- 실행 흐름: 어떻게 처리되는가
- 화면 흐름: 사용자는 무엇을 보게 되는가
- 확장성: 앞으로 어디까지 넓어지는가
- 경쟁 비교: 상대 제품의 강점은 인정하고 HeyGent의 작업 실행 흐름으로 답합니다.
